# RAG 검증 기록

이 문서는 로컬 RAG 파이프라인을 구현하면서 수행한 테스트·실험·오류 확인·수정 결과를 누적 기록한다.

## 검증 유형

| 유형 | 의미 |
|---|---|
| 단위 테스트 | 하나의 함수나 모듈을 외부 시스템 없이 검증 |
| 통합 테스트 | 여러 모듈 또는 실제 CLOVA API를 함께 검증 |
| Smoke test | 핵심 흐름이 최소 조건에서 동작하는지 빠르게 확인 |
| End-to-end 테스트 | 질문 입력부터 최종 답변·출력까지 전체 흐름 검증 |
| 회귀 테스트 | 수정 후 기존에 성공한 흐름이 계속 성공하는지 재확인 |

현재 기록의 실제 CLOVA 호출은 사용량이 발생할 수 있다. `test_data/`의 캐시와 로컬 색인은 재사용하므로 이미 처리한 문서를 불필요하게 다시 호출하지 않는다.

## 실행 기록

### 2026-08-23 segmentation 입력 크기 검증

- 대상: 첫 공시 XML 문서
- 전체 문서 약 328,000자 요청: HTTP 400
- 100,000자 요청: HTTP 408 Timeout
- 조치: client 기본 분할 30,000자, smoke test 기본 입력 20,000자로 조정
- 판단: 30,000자와 20,000자는 공식 최대값이 아니라 안정성 확인을 위한 보수적 운영 기준이다.

### 2026-08-23 문단 나누기 API smoke test 성공

- 입력: 첫 공시 문서 앞부분 20,000자
- 결과: 13,639 input tokens, 35개 문단
- 결과: 정상

### 2026-08-23 Embedding v2 단일 문단 검증

- 입력: 문단 1개, 336자
- 결과: 172 input tokens, 1024차원 벡터
- 결과: 정상

### 2026-08-23 segmentation·embedding 캐시 색인

- 대상: 첫 공시 문서
- 처리: 문단 3개를 Embedding v2로 생성해 로컬 Vector Store 저장
- 재실행: segmentation cache 1건, embedding 3건 재사용
- 결과: 중복 API 호출 없이 재실행 성공

### 2026-08-23 로컬 Vector 검색

- 대상: 저장된 3개 chunk
- 처리: 질문 Embedding v2 생성 후 cosine similarity 검색
- 결과: 검색 결과 반환 성공

### 2026-08-23 리랭커 연결 초기 검증

- 대상: 삼성전자 2023년 1분기 사업 질문
- 검색 문서: 표지·목차 중심 chunk 3개
- 결과: 리랭커 호출 성공, 구체적인 근거 부족으로 `cited_documents` 빈 배열 반환
- 판단: 검색·리랭커 구조는 정상이나 본문 chunk가 더 필요함

### 2026-08-23 본문 chunk 추가 및 리랭커 검증

- 처리: 목차 이후 본문 chunk 6개 추가
- 총 색인: 9개 chunk
- 결과: `사업의 개요`, `주요 제품 매출` 본문이 검색됨
- 결과: 리랭커가 관련 본문 2개를 cited document로 선택

### 2026-08-23 RAG Reasoning 2단계 호출 오류 및 수정

- 증상: 첫 tool call은 성공했으나 검색 결과를 전달하는 두 번째 호출에서 HTTP 400
- 원인: `tool` 메시지에 불필요한 `toolCalls` 필드를 함께 전달
- 수정: `role`, `toolCallId`, `content`만 포함
- 결과: RAG Reasoning 최종 답변과 인용 문서 반환 성공

### 2026-08-23 대회용 `/answer` 로컬 연결

- 입력: `question_id`와 2023년 삼성전자 질문
- 흐름: 질문 Embedding → 로컬 Vector Store → 리랭커 → RAG Reasoning → 최종 JSON
- 결과: `question_id`, `question`, `retrieved_context`, `think_trace`, `answer` 반환 성공

### 2026-08-23 삼성전자 공시 5개 문서 색인

- 대상: manifest 앞부분 삼성전자 공시 5개
- 처리: 문서별 본문 chunk 최대 3개
- 결과: 총 21개 chunk
- 결과: 여러 기간 공시에서 검색·리랭커·RAG Reasoning 동작 확인

### 2026-08-23 메타데이터 필터 구현

- 구현: 기업명·분기·공시 유형을 정규식·문자열 규칙으로 추출
- 예시: `삼성전자 2023년 1분기 분기보고서`
- 변환: `corp_name=삼성전자`, `report_period=2023-03`, `document_type=분기보고서`
- 애매한 질문: 필터 없이 전체 벡터 검색으로 fallback
